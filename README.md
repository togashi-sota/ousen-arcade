# 桜泉祭 ミニゲームアーケード（6本）

学校の文化祭「桜泉祭」（日本大学生産工学部 情報処理研究会）で展示したミニゲーム集です。
小さな子どもから大人まで、**遊び方のちがう6本・38モード**を、ブラウザだけで遊べます。

**▶ ブラウザで遊ぶ：https://togashi-sota.github.io/ousen-arcade/**
（パソコンの Chrome／Edge がおすすめ。`F` キーで全画面）

> 個人制作（企画は本人、プログラムの大部分は生成 AI の Claude Code が書きました。下の「作り方」）。
> このページの版は、展示した版をネットで遊べるようにしたコピーです。ルールと数値は展示版と同じで、ちがうのは画面に出る文字が2か所だけです（下の「このネット版で変えたこと」）。

---

## 6本のゲーム

| ゲーム | 遊び方 | 操作 | 誰に向けて |
|---|---|---|---|
| ドタバタホッケー | 2人対戦か CPU（4段階）と。5点先取。特殊なパックで変化がつく | キーボード（W/S・↑/↓） | 友達どうしの学生・大人 |
| もぐらたたきチャレンジ | 30秒でモグラを叩いて点数を競う | クリック／タップ | 誰でも（説明なしで始められる） |
| あわあわ潜水艇 | 押している間だけ浮く。障害物を避けて進んだ距離を競う | スペース1つ／クリック | 小さい子ども |
| おやつをパクッ！ | クマの好きな食べ物だけ食べさせる。押している間だけ口が開き、嫌いな物は口を閉じて見送る | スペース長押し／クリック長押し | 小さい子から（難しくすれば大人も） |
| ふわふわ！風船バレー | 1対1の風船バレー。自分のコートに落ちたら相手に1点、5点先取。長いラリーは30秒で風船が割れる | キーボード（A/D/W・←/→/↑） | 1対1で遊びたい人（1人なら CPU 戦） |
| なんびきパレード | 動物のパレードを見て、お題の動物が何匹いたかを数字で答える（1〜3人で協力） | 画面の数字パッドをクリック | 親子・グループ（1人でも遊べる） |

- 6本に共通の設計ルール
  - 操作はキー1〜3つか、マウスだけ
  - 難しさは操作ではなく、出てくるもの・速さ・判断や数える条件で足す（風船の種類、ネットの高さ、パレードのお題の条件なども難しさで変わる）
  - とつぜん変わる仕掛けは、**変わったことが分かるように画面で知らせる**
    （①ホッケーは出る0.6秒前、③潜水艇は来る前、⑤風船バレーはサーブ前2.5秒・風向きは1.5秒前に予告。
    ④おやつだけは変わると同時に表示。②もぐらと⑥パレードには途中で変わる仕掛けがありません）
- 6本・38モード・ランキング17種。
- **推奨はパソコンの Edge／Chrome** です（`F` キーで全画面）。
- **スマホ・タブレットでも開けます**が、画面が小さくなります。ホッケーと風船バレーはキーボードが必要です。
  タッチで遊ぶ処理が入っているのは、もぐらたたき・潜水艇・おやつ・パレードの4本です。
  **スマートフォンの実機では確認していません**（画面の幅を変えての確認だけです）。

## 作り方（役割分担）

- **本人**：6本という構成、各ゲームの**基本の遊び方**とターゲット、ルールと難易度の方針、
  実機での試遊と問題の発見、**改善の方向と、直すかどうかの決定**、展示の運営。
- **Claude Code（生成 AI）**：プログラムの実装、自動テスト、数値の検証、
  **細かい仕様・ギミック・数値・演出の案出し**。
- **ChatGPT（生成 AI）**：企画の壁打ち、仕様の整理、資料のレビュー。
- 細かな仕様や演出は生成 AI の提案も採用しています。それを実際に遊んで、
  **採用するか・直すか・やめるかを判断したのが本人**です。
- 絵・音はすべてプログラムで描画・合成しています（画像・音声ファイル、外部のライブラリは使っていません）。

## ファイルの見方

```
index.html          ゲームを選ぶ画面・あそびかた画面
assets/js/engine.js 6本で共通の仕組み（画面の切り替え・入力・記録）
assets/js/audio.js  効果音・音楽（プログラムで合成）
assets/js/ranking.js ランキング（このブラウザの中だけに保存）
games/<名前>/game.js 各ゲーム（hockey・mole・sub・snack・balloon・parade）
```

## このネット版で変えたこと（ルールと数値は変えていない）

- 記録の保存場所を展示版と分けた（`ousenArcadeWeb.`）。展示に来た人の記録は入っていません。
- いつ遊んでも1つのランキングにまとまるようにした（展示版は展示の日だけが本番の記録）。
- スマホ・タブレット向けの案内を画面の下に出すようにした。
- **画面に出る文字を2か所だけ直した**（2026-11-25）。おやつの「げきむず」の説明「鳥がさらう」→「鳥がすりかえる」（実装は すりかえ）、風船バレーの見出し「とくべつな 風船が 6しゅるい！」→「風船が 6しゅるい！ とくべつなのは 5つ」（6つのうち1つは ふつうの風船）。**どちらも表示の文字だけで、遊びかた・判定・数値は変えていません。**展示版はそのまま残してあります。

## プライバシー

- ページそのものは GitHub Pages から読み込まれますが、
  **読み込んだあと、ゲームの中から外へ通信することはありません**。
  公開しているファイル11本を検索して、`fetch`・`XMLHttpRequest`・`WebSocket`・`sendBeacon`・
  フォーム送信が**0件**であることを確かめています。外部のファイル（画像・音・ライブラリ）も読み込みません。
- ランキングと記録は、遊んだブラウザの中（localStorage）にだけ保存されます。
